# Drug Interaction and Dosage Matcher

Run it:

    pip install -r requirements.txt
    python app.py

Then open http://127.0.0.1:5000

Files: hash_table.py (chaining, linear probing, double hashing), bst.py (insert, delete, in-order,
predecessor, select, rank, rotations), data.py (made-up toy data), app.py (Flask server and 2-SUM),
templates/index.html (the web page).
